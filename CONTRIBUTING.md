# Contributing

Corrections, disconfirming evidence, reproducibility problems, and well-sourced counterarguments are welcome. Open a GitHub issue with a precise link to the affected file and the best available source.

For proposed research or code changes:

1. Use the relevant file in [`templates/`](templates/README.md).
2. Prefer primary sources and include publication and access dates.
3. Separate fact, estimate, assumption, and opinion.
4. Preserve earlier published views; add a dated update instead of rewriting history.
5. Disclose relevant positions or conflicts.
6. Do not include material non-public information, private account data, credentials, proprietary datasets, paid research, or copied articles and transcripts.
7. State any material LLM assistance and independently verify important claims.

The owner retains editorial control over investment conclusions. Accepting a factual correction does not imply agreement with a contributor's recommendation.
