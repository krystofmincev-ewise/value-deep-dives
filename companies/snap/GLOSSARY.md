# Snap research glossary and formula guide

This page translates the shorthand used across the Snap research dossier. Each substantive memo also expands its important terms at first use. Definitions describe how the term is used in this research; company-reported definitions can differ and are identified where that matters.

## How to read the numbers

| Shorthand | Plain-English meaning |
| --- | --- |
| `m` / `bn` | Million / billion. Dollar figures are United States dollars unless a memo says otherwise. |
| `x` | “Times,” usually a valuation multiple. For example, 1.7x revenue means enterprise value equals 1.7 times annual revenue. |
| `bps` | Basis points. One hundred basis points equal one percentage point. |
| `Q1`–`Q4` | First through fourth quarter. |
| `H1` / `H2` | First half / second half of a year. |
| `FY` | Fiscal year. Snap's fiscal year ends on 31 December. |
| `YoY` | Year over year: compared with the same period one year earlier. |
| `TTM` / `LTM` | Trailing twelve months / last twelve months. Both describe the most recent completed twelve-month period. |
| `NTM` | Next twelve months: a forward forecast period. |
| `Y1`–`Y5` | Forecast years one through five. |
| `NA` / `RoW` | North America / Rest of World, using Snap's reporting regions. |

## Users and operating metrics

| Acronym | Full term | Meaning here |
| --- | --- | --- |
| `DAU` | Daily active users | Snap's average number of registered users who open Snapchat on a given day during the quarter. |
| `MAU` | Monthly active users | Registered users active at least once during the month or company-defined measurement window. |
| `DAP` | Daily active people | Meta's estimated, de-duplicated daily users across its family of apps. It is not directly comparable with Snap's DAU. |
| `DAUq` / `WAUq` | Daily / weekly active uniques, quarterly average | Reddit's active-user denominators, including some logged-out users. |
| `ARPU` | Average revenue per user | Quarterly revenue divided by average daily active users under Snap's reported definition. |
| `FTE` | Full-time employee | Company-reported full-time headcount. |
| `KPI` | Key performance indicator | A metric used to evaluate operating progress. |
| `GMV` | Gross merchandise value | The value of commerce transacted before platform fees or other deductions. |

## Financial statements and valuation

| Acronym | Full term | Meaning here |
| --- | --- | --- |
| `GAAP` | Generally Accepted Accounting Principles | United States accounting rules used for Snap's filed financial statements. |
| `OCF` | Operating cash flow | Cash generated by operations. Some older source tables call this “cash flow from operations.” |
| `FCF` | Free cash flow | Snap's definition: operating cash flow minus purchases of property and equipment. |
| `SBC` | Stock-based compensation | Compensation paid through equity awards; a non-cash expense when recognized, but economically dilutive. |
| `EBITDA` | Earnings before interest, taxes, depreciation, and amortization | A non-GAAP operating-profit proxy. “Adjusted EBITDA” also removes Snap's stated adjustments, including stock-based compensation. |
| `R&D` | Research and development | Product and engineering expense. |
| `G&A` | General and administrative | Corporate, legal, finance, and other administrative expense. |
| `opex` | Operating expense | Research and development plus sales and marketing plus general and administrative expense in this dossier. |
| `capex` | Capital expenditure | Purchases of property and equipment. |
| `EPS` | Earnings per share | Net income or loss attributable to each weighted-average share under the stated accounting convention. |
| `P&L` | Profit and loss statement | Informal name for an income statement or a separately disclosed business-unit economics statement. |
| `EV` | Enterprise value | Fully diluted equity value plus net debt in the primary Snap bridge, excluding leases unless noted. |
| `DCF` | Discounted cash flow | A valuation that discounts forecast cash flows and terminal value to today. |
| `SOTP` | Sum of the parts | A valuation that values business components separately and then reconciles to equity value. |
| `CAGR` | Compound annual growth rate | The constant annual rate that connects a beginning value to an ending value over several years. |
| `PV` | Present value | A future amount after discounting it back to today. |
| `FD shares` | Fully diluted shares | Basic shares plus the modeled effect of awards and other potentially dilutive claims. |
| `QQQ` | Invesco QQQ Trust | The exchange-traded fund used here as a Nasdaq-100 benchmark proxy. |
| `VWAP` | Volume-weighted average price | Average traded share price weighted by trading volume over the stated period. |
| `SOFR` | Secured Overnight Financing Rate | A benchmark United States dollar interest rate used in floating-rate debt. |
| `SaaS` | Software as a service | Subscription software delivered as an ongoing service; not a clean valuation analogue for Snapchat+. |
| `P10` / `P50` / `P90` | Distribution percentiles | Values below which 10%, 50%, or 90% of simulated outcomes fall. P50 is the median. These are not scenario probabilities. |
| Monte Carlo simulation | Repeated model draws | A method that samples declared input distributions and dependencies to produce a valuation distribution. |
| Structured elicitation | Explicit analyst uncertainty inputs | A transparent set of judgmental marginals and dependencies used when no calibrated reference class exists; it is not historical calibration. |
| Bottom-tail expected value | Mean within a downside tail | The average modeled value among outcomes at or below a stated percentile, such as the bottom decile. |

## Advertising, measurement, and technology

| Acronym | Full term | Meaning here |
| --- | --- | --- |
| `AI` | Artificial intelligence | Software models that generate, classify, predict, rank, or automate work. |
| `ML` | Machine learning | Statistical learning systems, including ad and content recommendation models. |
| `AR` | Augmented reality | Digital objects or information overlaid on the physical world. |
| `DR` | Direct response | Advertising optimized for an observable action such as a purchase or app install. |
| `API` | Application programming interface | A documented way for software systems to exchange data or instructions. |
| `CAPI` | Conversions API (application programming interface) | Snap's server-to-server interface for sending conversion events. |
| `DPA` | Dynamic Product Ads | Ads assembled or selected from a product catalog for an individual user. |
| `CPM` | Cost per thousand impressions | Advertiser cost for one thousand ad impressions. |
| `eCPM` | Effective cost per thousand impressions | Advertising revenue per thousand delivered impressions; a platform-yield measure. |
| `CPC` | Cost per click | Advertiser spend divided by measured clicks. Some benchmarks use only link clicks, which is narrower than every interaction a platform may call a click. |
| `CTR` | Click-through rate | Measured clicks divided by advertising impressions. |
| Conversion rate | Conversions divided by clicks | The percentage of measured clicks that become the selected action, such as a purchase. |
| `CPA` | Cost per acquisition or action | Advertiser spend divided by the measured acquisitions or target actions. |
| `ROAS` | Return on ad spend | Attributed revenue divided by advertising spend. |
| `iROAS` | Incremental return on ad spend | Revenue caused by advertising, rather than merely attributed to it, divided by spend. |
| `ROI` | Return on investment | Gain relative to the amount invested. |
| `MMP` | Mobile measurement partner | An independent provider that measures app advertising and conversions. |
| `SKAN` | StoreKit Ad Network | Apple's privacy-preserving mobile-ad attribution framework, now branded AdAttributionKit. |
| `MMM` | Marketing mix modeling | Statistical estimation of how marketing channels contribute to outcomes. |
| `SMB` | Small and medium-sized business | Smaller advertisers, distinct from large enterprise accounts. |
| `DTC` | Direct to consumer | A brand selling directly to the end customer. |
| `CTA` | Call to action | The prompt asking a user to click, buy, install, or take another action. |
| `A/B test` | Controlled experiment | Users or campaigns are randomly assigned to variants to measure causal differences. |
| `LLM` | Large language model | A machine-learning model trained to understand or generate language and code. |
| `MMoE` / `PLE` | Multi-gate Mixture-of-Experts / Progressive Layered Extraction | Multi-task model architectures used in recommendation systems. |
| `GPU` | Graphics processing unit | A processor commonly used to train and run large machine-learning models. |
| `FLOP` | Floating-point operation | One arithmetic computation; FLOPs are a rough measure of computing work. |
| `MTIA` | Meta Training and Inference Accelerator | Meta's custom accelerator hardware for artificial-intelligence workloads. |
| `GEM` | Generative Ads Recommendation Model | Meta's name for its large advertising-recommendation model; the cited engineering material is the controlling definition. |
| `XR` | Extended reality | Umbrella term covering augmented, virtual, and mixed-reality technologies. |
| Auction liquidity | Relevant bidders and budget competing in an advertising auction | More liquidity makes it easier for better prediction to turn into higher publisher price. |
| Candidate retrieval | The first narrowing stage in recommendation | A fast model reduces millions of eligible items or ads to a manageable candidate set. |
| Cold start | A new user, item, or advertisement with little history | The system must predict outcomes before it has enough direct examples. |
| Calibration | Agreement between predicted probabilities and real frequencies | If events labeled 10% likely happen about one time in ten, the model is well calibrated. |
| Transformer | A model architecture that weighs relationships among signals in a sequence | It can learn which earlier behaviors matter for the next recommendation. |
| Multi-task prediction | One model learning several related outcomes together | Common events such as views can help the system learn rarer events such as purchases or complaints. |
| Attribution | Assigning credit for an observed outcome | A platform can attribute a sale to an ad even when the customer might have bought anyway. |
| Incrementality | The outcome caused by the advertisement | Usually requires a holdout experiment or causal model that estimates what would have happened without the ad. |
| Pixel | Browser code that reports website events to an advertising platform | A purchase can be reported by both a Pixel and a server connection, creating a need for deduplication. |
| Deduplication | Removing duplicate reports of the same event | It prevents one purchase from being counted twice when signals arrive through multiple routes. |
| Unified Attribution | Snap's beta measurement product | It attempts to combine multiple attribution views; beta status means maturity and availability can still change. |
| Seven-day-click/no-view optimization | A strict attribution setting | It counts an outcome within seven days after a click and gives no credit to an advertisement that was merely viewed. |

## Formula guide

These are the recurring author calculations. Inputs are stated in the memo where each formula is used.

```text
Year-over-year growth = current-period value / prior-year value - 1

Margin = profit or cash-flow measure / revenue
Gross margin = (revenue - cost of revenue) / revenue

ARPU = quarterly revenue / average DAU

FCF = OCF - purchases of property and equipment
Net debt = debt - cash - marketable securities

Fully diluted equity value = share price × fully diluted shares
EV = fully diluted equity value + net debt
EV/revenue = enterprise value / revenue

Simulated value per draw = median(revenue-multiple value, SOTP value, DCF value)
Distribution mean = Σ simulated values / number of draws
Expected return = distribution mean / reference price - 1
P10 / P50 / P90 = value below which 10% / 50% / 90% of draws fall
Bottom-tail expected value = mean value among draws at or below the stated tail quantile

Portfolio loss contribution ≈ position weight × security drawdown

CAGR = (ending value / beginning value)^(1 / number of years) - 1

DCF value/share = Σ [FCF per share in year t / (1 + discount rate)^t]
                + terminal value per share / (1 + discount rate)^n

Terminal value = final-year FCF × (1 + terminal growth)
                 / (discount rate - terminal growth)

SOTP value/share = [Σ (segment revenue × segment multiple)
                    + non-operating option value - net debt]
                   / fully diluted shares

Advertising revenue ≈ impressions × eCPM / 1,000
Advertising growth = (1 + impression growth) × (1 + eCPM growth) - 1

CPM = advertising spend / impressions × 1,000
CPC = advertising spend / clicks
CTR = clicks / impressions
Conversion rate = conversions / clicks
CPA = advertising spend / conversions
ROAS = attributed revenue / advertising spend
iROAS = revenue caused by advertising / advertising spend
eCPM = publisher advertising revenue / delivered impressions × 1,000
```

## Evidence labels

- **Fact:** reported by a filing, regulator, company, or stated dataset.
- **Calculation:** arithmetic from disclosed inputs.
- **Estimate / assumption:** an analyst input, not a company fact.
- **Inference:** the analyst's interpretation of evidence.
- **Issuer claim:** a first-party statement whose outcome is not independently audited.
