# Shared data

This folder is reserved for small, redistributable datasets that support several studies. Company- or experiment-specific data belongs next to that work.

Every dataset must include a README or manifest with:

- source URL, publisher, version, and access date;
- license and redistribution basis;
- information cutoff and units;
- schema and missing-value conventions;
- transformations or build script;
- checksum when it helps reproducibility;
- studies and experiments that consume it.

For large, proprietary, paid, or restricted data, store only metadata and reproducible acquisition/build instructions. See the repository [data policy](../DATA_POLICY.md).
