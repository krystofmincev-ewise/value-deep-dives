# Discovery research

Discovery work explains where company ideas came from and preserves the opportunity set—not only the names eventually selected for deep dives.

| Area | Use |
| --- | --- |
| [Screens](screens/README.md) | Dated, reproducible candidate searches with frozen result cohorts |
| [Sectors](sectors/README.md) | Industry structure, economics, value chains, and company maps |
| [Themes](themes/README.md) | Cross-sector theses such as AI infrastructure demand or ad-signal loss |

Every discovery study should state its information cutoff, universe, data sources, formulas, filters, exclusions, ranking method, complete results where licensing permits, and promotion/pass criteria. Company dossiers should link back to the study that surfaced them.

Use the [discovery study template](../templates/discovery-study.md).
