# Screens

Screens are dated snapshots of a defined universe. Store each as:

```text
YYYY-MM-DD-screen-name/
├── README.md       # question, method, results, limitations, decisions
├── results.csv     # complete frozen cohort when redistribution is allowed
└── sources.md      # data provenance and licenses
```

A screen may begin with valuation—for example, price-to-sales near 1×—but should account for cash, debt, dilution, cyclicality, and business quality before treating companies as comparable. Avoid describing a low multiple as “oversold” unless a technical rule defines that term.
