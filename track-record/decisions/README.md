# Decision records

Decision records connect research to an action without requiring disclosure of private account details. A record may be `buy`, `add`, `reduce`, `exit`, `watch`, or `pass`.

Each file uses `YYYY-MM-DD-ticker-action.md` and should state the timestamp, research available at the time, action, public reference price or actual fill (clearly labelled), horizon, expected return logic, downside, falsifiers, review trigger, and dated position disclosure.

Position size and personal fill can be omitted. If so, state that explicitly. Do not infer a personal trade from the public reference price.
