# Retrospectives

Retrospectives evaluate the outcome without rewriting the original thesis. They should separate:

- security return and benchmark-relative return;
- whether the predicted business developments occurred;
- decision and sizing quality when disclosed;
- research-process strengths and failures;
- luck, market exposure, and unanticipated events;
- lessons that will change future work.

Successes and failures use the same template. No retrospective has been published yet. Use the [retrospective template](../../templates/retrospective.md).
